# MVP执行基线

## 角色分工

- Codex 中枢：整合产品、设计、后端、前端、测试产物，控制文件边界和验收。
- 产品经理：补齐 PRD、状态机、异常规则，默认按已确认规则推进。
- 后端工程师：数据模型、接口协议、冲突校验、未到限制、权限隔离。
- 设计师/前端：页面路由、低保真结构、首批页面骨架。
- 测试工程师：P0 用例、异常场景、权限和验收清单。

## 本轮落地范围

- 建立微信小程序工程骨架。
- 建立云函数 API 分发骨架。
- 建立共享状态常量和 mock 数据。
- 先做 6 个首批页面：用户首页、预约页、我的预约、员工工作台、到店核实、商家后台首页。

## 已采用默认规则

- 营业时间 24 小时。
- 桌台 40 张，按普台、乔氏银腿、独牙、乔氏金腿、乔氏玫瑰金分级。
- 一期不收定金，不接支付、灯控、收银。
- 用户提交“我已到店”，员工核实后开台。
- 用户至少提前 30 分钟预约。
- 未到店限制预约 3 天，店长可解除。
- 助教支持单独预约。
- 活动报名需要微信昵称和手机号授权。
