## Moodboard 提炼

### 空间视觉

- 黑顶和深灰墙面是主体，形成夜场和会所感。
- 球桌必须成为视觉中心，绿色台呢提供最强识别点。
- 吊灯通常是矩形、六边形或长条灯箱，适合转译成首页 hero 的青蓝灯线。
- 门头常用大字 + 青色霓虹轮廓，适合转译成小程序首页品牌标题。

### 色彩

- 主背景：近黑、深墨绿、深灰。
- 主识别：台呢绿。
- 霓虹线：青蓝。
- 辅助热度：橙 / 金，用在热门、价格、活动。
- 错误与危险：红色，限制使用。

### 组件语言

- 大 hero 不应只放文字，要有球桌场景或抽象球桌视觉。
- 桌台分类应像“桌型灯牌”，而不是普通 tab。
- 店内实时状态应像小型电子屏，突出空桌、总桌、使用中。
- 活动图卡可做灯牌感，但正文阅读必须清楚。

### 产品信息结构

- 首页：空桌、预约 CTA、桌型分类、店内实时、活动。
- 预约页：时间 / 时长 / 人数、桌台卡、助教卡、提交。
- 我的页面：预约记录、到店动作、状态。
- 工作台：待核实、开台、关台、桌台状态。

## 首页重做方案

### 首页目标

让用户一打开就感到“这是一个有氛围的台球俱乐部”，同时立即知道能不能约、点哪里约。

### 首页结构

```text
大视觉 Hero
- LIVE TABLE BOOKING
- 门店名
- 营业时间 / 桌台数 / 到店核实
- 抽象球桌场景：青蓝灯线 + 绿色球桌 + 球和杆线
- 当前空桌 / 空闲助教
- 店内实时 badge
- 立即预约桌台

今日可约分类
- 普台
- 银腿
- 独牙
- 金腿

快捷入口
- 分区时段价
- 陪练服务

店内实时
- 空闲桌台
- 总桌台 / 桌型

门店活动
- 活动名
- 名额
- 状态

预约规则
- 提前预约
- 爽约限制
- 到店核实
```

- `miniprogram/pages/home/index.wxss`：新增抽象球桌视觉、青蓝灯线、霓虹标题、桌型灯牌、店内实时电子屏样式。

## 预约页重做方案

### 预约页目标

保持工具效率，不做大图营销。预约页的 Dark Neon 应该体现在桌台卡、选中态、状态标签和底部提交，而不是再放一个大 hero。

### 预约页结构

```text
深色页头
- 桌台预约
- 选好时段，到店即开

预约控制台
- 开始时间
- 时长步进
- 人数步进
- 热门时段提示

桌台选择
- 两列桌台卡
- 编号最大
- 状态右上
- 区域 / 类型
- 价格暖金
- 选中态台呢绿发光

助教选择
- 单列助教卡
- 姓名 / 标签 / 价格 / 状态

底部固定提交
- 提交预约
```

### 预约页前端建议

- 当前预约页已有深色选中态，可继续强化底部固定提交区。
- 桌台卡加入“桌型灯牌”小标签，例如普台、银腿、独牙、金腿。
- 加载态从纯文本改为 2 张桌台卡骨架。

## QA 视觉验收标准

- 首页必须能看到明显球桌视觉，不允许只有深色卡片。
- 首页必须包含大 CTA、今日可约分类、店内实时、门店活动图卡或灯牌感模块。
- 深色主题下正文、按钮、标签必须可读。
- 霓虹元素只能作为灯线、标题光感、状态点，不能满屏发光。
- 桌台分类不能像普通文字 tab，必须有可点击卡片或灯牌感。
- 预约页桌台选中态必须明显。
- 我的预约、工作台、活动报名、预约详情不得退化为裸文本。
- 微信开发者工具至少截图：首页、预约页、我的预约、工作台、活动报名、预约详情。
