- 手机号授权、真实用户权限、员工/店长多账号、真实开发者工具 GUI 截图仍待补证。
- `bootstrapMvp`、烟测 action 等测试辅助能力需要与生产能力隔离。

## 6. P2 延后模块

| 模块 | 延后原因 | 当前处理 |
|---|---|---|
| 支付、储值闭环、退款 | 涉及微信支付、资金、回调幂等和真实商户号 | 一期不做；个人中心仅只读展示 |
| 优惠券/会员卡完整核销 | 会牵动支付、收银、会员权益、核销规则 | 仅保留只读入口和后台配置占位 |
| 多门店总部管理 | 当前业务已确认单店 MVP，但表保留 `store_id` | 只做单店隔离，不做总部切换 |
| 灯控、收银、计时硬件 | 依赖真实硬件/第三方系统 | 明确不接入 |
| 桌台二维码 | 用户已明确一期先不用做 | 不纳入本轮补齐 |
| 自动化营销群发 | 合规和触达渠道不确定 | 只做触达口径规划，不做群发能力 |
| UI 风格重做 | 本轮目标是功能模块补齐 | 等用户提供新 UI 样式模板后再启动 |
