# UI 审计与核心页面重设计标准

日期：2026-06-14

## 本轮执行 agent

- 设计师 Agent
- lane：visual-design

## 设计读取

这是台球俱乐部门店预约小程序，不是营销落地页。用户核心任务是在手机上快速判断空桌、预约、到店、让员工核实开台。视觉方向应偏安静、清晰、有门店质感的工具型 UI。

本轮联网参考了“西安 W 台球昆明路店”的公开描述：整体采用现代工业风，以深灰与木色为主调，柔和射灯营造专注放松的氛围，并强调周末晚间线上提前锁台。该信息适合转译为小程序的深灰底、暖木金、台呢绿、清晰状态和预约优先级。

## 视觉审计结论

### P0 问题

- 首页曾出现裸文本堆叠，说明页面样式兜底和视觉验收缺位。
- 多个页面依赖同一套基础类名，但页面结构仍偏“标题、卡片、标签”的功能堆叠，缺少门店场景感。

### P1 问题

- 首页没有足够突出“当前空桌”和“立即预约”的第一优先级。
- 预约页桌台、助教、价格、选中态层级不够强，用户需要读完整卡片才能判断。
- 工作台、我的预约、预约详情视觉可用，但状态流转、待处理优先级还可以继续增强。
- 空、错、加载状态多为普通文本，后续应统一为固定组件。

## 设计系统

### 色彩

- 页面基底：`#101612` 深灰黑，模拟球房暗环境。
- 内容纸面：`#fffdf8`，用于主面板和卡片，避免纯白刺眼。
- 页面浅底：`#f3f0e8`，用于内容区背景。
- 主操作色：`#0f5b4a` 台呢绿。
- 强调色：`#c7a766` 暖木金，用于预约 CTA、价格、门店质感点缀。
- 危险色：`#b43e32`，只用于错误、取消、限制。

### 间距与圆角

- 页面外边距：`24rpx`。
- 区块间距：`24rpx`。
- 卡片内边距：`24rpx` 到 `26rpx`。
- 面板圆角：`18rpx`。
- 主视觉圆角：`24rpx`。
- 按钮圆角：`16rpx`。

### 字体层级

- 大标题：`48rpx / 900`，仅用于页面首屏标题。
- 区块标题：`34rpx / 800`。
- 列表主信息：`29rpx / 800`。
- 正文与辅助信息：`26rpx`，颜色 `#65716b`。
- 数字指标：`56rpx / 900`，使用 tabular numeric。

### 组件规范

- Hero：只用于首页和工作台关键待处理入口。必须包含一个明确主任务、最多两个指标和一个主按钮。
- Panel：承载表单、规则、状态流转等成组内容。
- Action Card：承载快捷入口，需有标签、标题、辅助说明，不超过两列。
- Selectable Card：用于桌台、助教选择。选中态使用台呢绿边框、浅绿底、右下角圆点。
- Tag：用于短状态，不承担主按钮职责。
- Button：主按钮用台呢绿；最高优先级预约 CTA 可用暖木金；错误按钮用红色。

## 核心页面改版规范

### 首页

- 第一屏必须优先呈现门店名称、营业信息、桌台总量、当前空桌、空闲助教、立即预约。
- 活动和服务入口放在首屏下方，避免抢占预约路径。
- 门店规则只保留关键限制：提前预约时间、爽约限制、到店核实。

### 预约页

- 顶部先显示预约条件：开始时间、时长、人数、提前预约限制。
- 时长和人数使用步进器，不用普通文本按钮。
- 桌台卡必须突出桌台编号、区域、类型、价格和状态。
- 助教卡必须突出姓名、标签、价格和状态。
- 提交按钮保持页面末尾，后续可由前端升级为底部吸附。

### 我的预约

- 卡片第一行显示桌台与类型，右侧状态。
- 待到店状态的“我已到店”按钮必须醒目；非待到店状态后续应弱化或隐藏按钮。
- 空状态使用“暂无预约 + 去预约”路径，后续建议补跳转按钮。

### 工作台

- 工作台第一屏突出“待核实”数量，优先于普通今日预约列表。
- 桌台网格入口保留为次级入口。
- 今日预约列表建议按状态分组：待核实、使用中、已完成。

### 活动报名

- 表单输入和授权按钮统一使用 `14rpx` 圆角。
- 手机号输入优先可读性，授权按钮不与主提交按钮争抢视觉层级。
- 人数选择沿用预约页步进器视觉。

### 预约详情

- 顶部显示桌台、时间、当前状态。
- 状态流转建议后续改为竖向时间线，当前节点使用台呢绿高亮。
- 到店说明保持短句，避免大段规则文本。

## 空、错、加载状态

- Loading：用面板承载，文案格式为“正在加载xxx...”，后续建议加骨架屏。
- Empty：用 `.panel.empty`，必须包含标题和下一步路径。
- Error：用 `.status-danger`，错误面板不使用强阴影，避免像主内容。
- Disabled：后续按钮应降低透明度并禁止 active 动效。

## 建议前端实施清单

- 将我的预约待到店状态按钮按状态控制显示或禁用。
- 将预约详情状态流转升级为竖向时间线。
- 工作台今日预约按状态分组，并给待核实加高优先级视觉。
- 为 loading 增加骨架屏组件，替代纯文本。
- 用微信开发者工具补首页、预约、我的预约、工作台、活动报名、预约详情截图回归。

## 视觉验收标准

- 任何核心页面不得出现裸文本堆叠。
- 首屏必须能在 3 秒内看出当前页面主任务。
- 主要按钮、状态标签、价格、错误提示必须可一眼区分。
- 不使用廉价大渐变、过度装饰、随机色彩或营销页式夸张 hero。
- 页面文字不得重叠，不得被按钮或卡片遮挡。
- 所有核心页面必须有 loading、empty、error 至少一种可识别兜底。
