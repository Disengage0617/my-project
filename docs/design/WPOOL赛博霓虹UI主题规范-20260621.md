# W POOL 赛博霓虹 UI 主题规范

日期：2026-06-21

## 本轮执行 agent

- UI设计师 Agent
- 前端工程师 Agent
- lane：visual-design / frontend

## 主题真源

用户选定的视觉目标为 W POOL 赛博霓虹模板：深黑底、青紫双色霓虹、玻璃卡片、发光主按钮、品牌 W 标识、底部 tabBar 发光图标。

后续新增模块必须沿用该主题，不得回退到浅色卡片、普通深绿、裸文本堆叠或无图标底部栏。

## 核心视觉规则

- 页面底色：`#03050b` 到 `#020409` 的深黑渐变。
- 主霓虹色：青色 `#22f5ff`。
- 辅助霓虹色：紫粉 `#e044ff`。
- 辅助强调：会员、排行、价格使用暖金 `#ffd470`。
- 卡片：深色玻璃态，`20rpx-24rpx` 圆角，细青色边框，少量内发光。
- 标题：首屏主标题使用大字号、粗字重和轻微青紫辉光。
- CTA：青紫渐变边框与发光，按钮文本大而清晰。
- tabBar：5 个入口固定为 首页 / 预约 / 订单 / 助教 / 我的，必须使用 PNG 图标，选中态有青紫辉光。

## 当前已落地页面

- `miniprogram/pages/reservation/`：预约桌台页，包含品牌头、球桌 hero、日期/时段 chips、桌台图片卡、助教选择和发光预约 CTA。
- `miniprogram/pages/mine/`：我的页，包含会员 hero、等级进度、权益数据、选的预约和常用功能宫格。
- `miniprogram/pages/assistant-list/`：助教页，包含专业助教 hero、人气推荐 tabs、排行教练卡和预约按钮。
- `miniprogram/app.json`：底部 tabBar 改为 首页 / 预约 / 订单 / 助教 / 我的，并接入发光 PNG 图标。

## 后续新增模块要求

- 新页面必须优先复用当前页面的品牌头、section 标题、玻璃面板、chips、列表卡、发光 CTA 和 tabBar 图标语言。
- 业务信息密度可以高，但必须保持行距、分组和状态层级，避免一页全是卡片堆叠。
- 图标不得缺失；没有现成图标时先生成或补充 PNG/SVG 资源，再接入页面。
- 微信开发者工具验收必须看首页、预约、订单、助教、我的五个底部入口是否全部展示图标和选中态。
