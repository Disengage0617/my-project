# 前端 UI 板块阶段验收报告

## 1. 本板块目标

补齐小程序前端页面的第一版产品化 UI，消除骨架感、乱码、调试痕迹和关键状态缺失。

本板块不判定完整产品完成，只验收前端 UI 第一轮覆盖是否达标。

## 2. 本轮执行 Agent

- Codex 中枢：统一指派、合并、验证。
- 设计师 Agent：统一视觉系统、页面信息层级、交互状态。
- 前端工程师 Agent：实现页面、状态、错误提示、提交中保护。
- 测试工程师 Agent：解析、乱码、WXML、mock 链路、后端回归。
- 验收官 Agent：对照本板块目标做阶段检核。

## 3. 已完成页面

### 用户端

- 首页：门店概览、当前空桌、空闲助教、活动入口、预约规则。
- 预约页：预约条件、时长/人数步进、桌台选择、助教选择、规则确认、提交中保护。
- 我的预约：列表、状态、到店提交、空态、失败态。
- 预约详情：桌台、时段、助教、状态流转、到店说明。
- 价格页：桌台分区价格、助教价格。
- 助教列表：助教状态、标签、介绍、价格、预约入口。
- 助教预约：时段、时长、提交中、规则说明。
- 活动列表：活动状态、时间、名额、剩余名额。
- 活动详情：活动规则、名额、报名入口。
- 活动报名：用户信息、参与人数、提交中、报名规则。

### 员工/商家端

- 员工工作台：待核实、桌台网格入口、今日预约。
- 到店核实：预约信息、状态流转、确认到店、开台、关台、标记未到。
- 桌台网格：桌台状态、空态、失败态。
- 商家后台首页：运营概览、配置完整度、下一步能力提示。
- 商家配置中心：配置项信息架构和接口待接入状态。
- 爽约限制：限制记录、状态、解除操作。
