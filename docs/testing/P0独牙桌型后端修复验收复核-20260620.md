## 6. 是否可以找用户手动复核

可以。

建议中枢现在找用户做最小手动复核：

1. 在微信开发者工具清缓存。
2. 重新编译小程序。
3. 从首页进入预约页。
4. 选择桌型“独牙”。
5. 预期看到 C01-C08，共 8 张。

这一步是“用户手动复核节点”，不是最终验收节点。

## 7. 手动仍失败时下一步负责 agent

如果用户手动清缓存、重新编译后仍然显示独牙 0 张：

- 下一步负责 agent：后端工程师 Agent。
- lane：backend。
- 重点检查：
  - 当前微信开发者工具是否调用真实云端而不是本地 mock。
  - 云函数是否已部署到包含本次修复的版本。
  - 真实云数据库 `billiard_table` 是否仍是旧的 3 张数据。
  - 是否需要在用户授权后执行安全的数据初始化、迁移或测试数据修复。

若后端确认真实数据已更新但页面仍为 0 张，再交测试工程师 Agent 做前端请求 payload、接口返回和页面过滤链路复核。
