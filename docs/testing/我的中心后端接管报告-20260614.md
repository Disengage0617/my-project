# 我的中心后端接管报告 - 2026-06-14

## 本轮执行 agent

- 后端工程师 Agent

## 接口

- `getMineCenter`：返回用户资料、授权状态、储值余额、优惠券、订单、预约摘要、助教预约、活动报名、爽约限制。
- `getMyReservations`：同步补齐预约列表桌台摘要，避免展示原始 `table_id`。

## 返回字段重点

- `profile`：昵称、头像、会员等级、手机号授权状态、预约数、爽约数。
- `auth`：登录状态、openid、资料授权、手机号授权、支付开关。
- `wallet`：余额分值、余额展示文案、储值展示开关、支付/充值禁用开关。
- `summary`：预约、优惠券、订单、爽约限制数量。
- `reservations`：补齐 `table`、`tableCode`、`tableType`。

## 权限规则

- 必须有 `OPENID`，否则返回 `UNAUTHORIZED`。
- 只读取当前 `OPENID` 对应数据。
- 第一期开关：不接微信支付，不开放充值，`paymentEnabled=false`、`rechargeEnabled=false`。
