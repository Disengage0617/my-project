## 3. 预约状态机

| 当前状态 | 动作 | 目标状态 | 操作端 | 关键副作用 |
|---|---|---|---|---|
| - | 创建预约 | 待到店 | 用户端 | 校验 30 分钟、桌台冲突、未到限制 |
| 待到店 | 我已到店 | 待核实 | 用户端 | 员工工作台出现待核实 |
| 待核实 | 确认到店 | 已到店 | 员工端 | 记录确认员工和时间 |
| 待核实 | 驳回到店 | 待到店 | 员工端 | 记录驳回员工和时间 |
| 已到店 | 开台 | 进行中 | 员工端 | 桌台状态变使用中，写状态流水 |
| 进行中 | 关台 | 已完成 | 员工端 | 桌台状态变空闲或清洁中，写状态流水 |
| 待到店/待核实 | 标记未到 | 未到店 | 员工端 | 写 no_show_record，限制 3 天预约 |
| 待到店/待核实 | 超时释放 | 已释放 | 员工端/定时任务 | 释放预约占用 |

## 4. 桌台状态机

| 状态 | 可执行动作 |
|---|---|
| 空闲 | 创建预约、手动停用、设为维修 |
| 已预约 | 等待用户到店、超时释放 |
| 使用中 | 关台 |
| 清洁中 | 设为空闲 |
| 维修中 | 设为空闲或停用 |
| 停用 | 重新启用 |

## 5. 助教预约状态机

| 当前状态 | 动作 | 目标状态 |
|---|---|---|
| - | 创建助教预约 | 待确认 |
| 待确认 | 员工确认 | 已确认 |
| 已确认 | 服务完成 | 已完成 |
| 待确认/已确认 | 取消 | 已取消 |

## 6. 活动报名状态机

| 条件 | 目标状态 |
|---|---|
| 未授权昵称或手机号 | 拒绝报名 |
| 活动满额 | 拒绝报名 |
| 活动需审核 | 待审核 |
| 活动不需审核 | 报名成功 |

## 7. 本轮验收点

- 用户提前 30 分钟以内预约被拒绝。
- 同桌重叠时段预约被拒绝。
- 用户点击“我已到店”后，预约进入待核实。
- 员工确认到店后，可开台；开台后可关台。
- 员工标记未到后，用户 3 天内不可预约。
- 助教单独预约校验同助教时段冲突。
- 活动报名必须带微信昵称和手机号。
- 40 张桌台 mock 数据按 A/B/C/D/E 分区生成。
