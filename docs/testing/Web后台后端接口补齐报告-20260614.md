# Web 后台后端接口补齐报告 - 2026-06-14

## 本轮执行 agent

- 后端工程师 Agent

## 接口清单

- `getAdminDashboard`：后台概览指标、近期预约、近期审计日志。
- `getAdminReservations`：后台预约列表，补充 `table/tableCode/tableType`。
- `getPageConfig`：小程序读取 `published` 页面配置；无配置时返回默认首页配置。
- `managePageConfig`：店长/管理员保存草稿、发布页面配置。
- `getAssets`：店长/管理员查询素材库，默认过滤软删除素材。
- `manageAssets`：店长/管理员新增、更新、软删除素材。
- `getAuditLogs`：店长/管理员查询审计日志。
- 复用配置写接口：`manageStore`、`manageTables`、`managePriceRules`、`manageAssistants`、`manageCampaigns`。

## 数据结构

- 新增/补齐 `page_config`：`store_id`、`page_key`、`status`、`theme`、`modules`、`published_at`。
- 新增/补齐 `asset`：`store_id`、`name`、`type`、`url`、`file_id`、`status`、`is_deleted`。
- `seed.js` 和 `bootstrapMvp` 已写入 `page_config` 与 `asset` 示例数据。

## 权限规则

- `getPageConfig`：公开读取，仅返回指定状态，默认 `published`。
- 后台概览、素材、审计、页面配置写入：`manager` 及以上。
- 商家配置写入：`manager` 及以上。
- 普通员工不能写门店、桌台、价格、助教、活动、素材、页面配置。
- 所有写操作按 `store_id` 隔离并写入 `audit_log`。
