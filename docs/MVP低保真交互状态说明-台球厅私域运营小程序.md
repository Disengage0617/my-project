# MVP低保真交互状态说明：台球厅私域运营小程序

## 1. 说明边界

- 本文只描述低保真信息架构与关键交互状态，不做视觉大稿。
- 页面依据当前 `app.json` 路由和《MVP页面路由与状态机》整理。
- 本轮重点覆盖：用户首页、预约页、员工工作台、商家后台首页。
- 状态沿用现有状态机：预约、桌台、助教预约、活动报名。

## 2. 全局导航关系

| 角色 | 一级入口 | 关键二级页 | 主要任务 |
|---|---|---|---|
| 用户 | `pages/home/index` 首页 | 预约、门店价格、助教、活动、我的预约 | 看空桌、发起预约、报名活动、查看预约状态 |
| 用户 | `pages/reservation/index` 预约 | 我的预约、预约详情 | 选择时间、桌台、助教并提交预约 |
| 员工 | `pages/staff-workbench/index` 工作台 | 到店核实、桌台网格 | 核实到店、开台、关台、标记未到 |
| 商家 | `pages/merchant-dashboard/index` 后台首页 | 商家配置、爽约限制 | 看经营概览、进入配置与风控处理 |

## 3. 用户首页

路由：`pages/home/index`

### 信息架构

| 层级 | 模块 | 内容 | 交互 |
|---|---|---|---|
| 1 | 门店摘要 | 门店名、营业时间、桌台总数 | 点击可进入 `pages/store-price/index` |
| 2 | 实时资源概览 | 当前空桌数、空闲助教数 | 点击空桌进入预约；点击助教进入助教列表 |
| 3 | 主行动 | 立即预约 | 跳转 `pages/reservation/index` |
| 4 | 预约规则 | 提前 30 分钟、未到限制 3 天等规则 | 仅说明，减少用户提交后才失败 |
| 5 | 近期活动 | 活动标题、名额、状态文案 | 点击进入活动详情或报名链路 |

### 关键状态

| 状态 | 页面表现 | 操作规则 |
|---|---|---|
| 加载中 | 骨架占位：门店摘要、两个指标卡、活动列表占位 | 不允许点击主行动，避免重复跳转 |
| 正常营业 | 显示营业时间、空桌、空闲助教和活动 | 立即预约为最高优先级入口 |
| 无空桌 | 空桌数显示 0，预约入口保留 | 进入预约页后桌台列表为空或仅展示不可选状态 |
| 无空闲助教 | 空闲助教数显示 0 | 助教入口可进入列表，但空闲项不可选 |
| 无活动 | 活动模块显示空状态 | 不展示报名按钮，只保留“暂无活动”文案 |
| 接口失败 | 显示轻量错误和重试入口 | 不展示过期 mock 数据为真实库存 |

### 低保真线框

```text
[门店名 + 营业时间 + 桌台数]

[当前空桌 37] [空闲助教 1]

[立即预约]

[预约规则]
提前30分钟 / 未到限制3天

[近期活动]
- 周末新手交流赛  12/32  直接报名
- 玫瑰金区会员练习夜  16/16  需审核
```

## 4. 预约页

路由：`pages/reservation/index`

### 信息架构

| 层级 | 模块 | 内容 | 交互 |
|---|---|---|---|
| 1 | 预约条件 | 开始时间、时长、人数 | MVP 可先用默认值，后续接入选择器 |
| 2 | 桌台选择 | 桌号、区域、桌台类型、价格、桌台状态 | 仅空闲桌台可选；选中后进入确认区 |
| 3 | 助教需求 | 助教姓名、标签、价格、状态 | 可不选；空闲助教可选 |
| 4 | 提交确认 | 规则提示、预约摘要、提交按钮 | 提交成功跳转 `pages/my-reservations/index` |

### 关键状态

| 状态 | 页面表现 | 操作规则 |
|---|---|---|
| 初始默认 | 开始时间默认为当前时间后约 40 分钟并取整 | 符合提前 30 分钟规则 |
| 未选桌台 | 提交按钮置弱或提交时报错提示 | 必须选择桌台 |
| 桌台可选 | 桌台状态为“空闲” | 可点击选中，展示选中态 |
| 桌台不可选 | 状态为已预约、使用中、清洁中、维修中、停用 | 可展示但不可提交 |
| 选择助教 | 助教状态为空闲 | 作为可选附加需求写入预约 |
| 助教不可用 | 状态为已预约、上钟中、休息中、未上班、已下班 | 不可选择或选择时提示不可用 |
| 预约冲突 | 后端返回桌台/助教时段冲突 | 保留用户已填条件，提示重新选择 |
| 提前不足 30 分钟 | 后端拒绝创建 | 提示“需提前 30 分钟预约”，引导调整时间 |
| 爽约限制 | 后端返回 3 天限制 | 阻止提交，提示限制到期时间 |
| 提交中 | 提交按钮 loading | 禁止重复提交 |
| 提交成功 | toast 后跳转我的预约 | 新预约状态为“待到店” |

### 低保真线框

```text
[预约桌台]
开始时间 20:00 | 2小时 | 2人 | 提前30分钟

[选择桌台]
[A01 空闲 普台 38元/小时] [B01 已预约 银腿 48元/小时]
[C03 空闲 独牙 58元/小时] ...

[助教需求]
[小周 空闲 走位/入门陪练 80元/小时]
[阿林 上钟中 进阶/比赛训练 120元/小时]

[提交确认]
一期不收定金；到店后点击“我已到店”，员工核实后开台。

[提交预约]
```

## 5. 员工工作台

路由：`pages/staff-workbench/index`

### 信息架构

| 层级 | 模块 | 内容 | 交互 |
|---|---|---|---|
| 1 | 工作台标题 | 工作范围说明：确认到店、开台、关台、标记未到 | 无 |
| 2 | 待核实卡片 | 待核实数量 | 点击进入 `pages/arrival-review/index` |
| 3 | 今日预约列表 | 用户、桌台、时段、预约状态 | 点击后进入到店核实或预约详情 |
| 4 | 桌台运营入口 | 40 张桌台状态网格 | 进入 `pages/table-grid/index` |

### 关键状态

| 状态 | 页面表现 | 操作规则 |
|---|---|---|
| 无待核实 | 待核实数量为 0 | 到店核实入口保留，但显示空状态 |
| 有待核实 | 待核实数量突出显示 | 优先处理“待核实”预约 |
| 待到店 | 今日预约列表显示状态 | 可等待用户提交到店，必要时标记未到 |
| 待核实 | 列表状态高亮 | 员工可确认到店或驳回到店 |
| 已到店 | 可进入开台动作 | 开台后预约进入“进行中”，桌台变“使用中” |
| 进行中 | 可进入关台动作 | 关台后预约进入“已完成”，桌台进入空闲或清洁中 |
| 未到店 | 列表显示结果态 | 写入爽约记录，触发 3 天预约限制 |
| 今日无预约 | 列表显示空状态 | 保留桌台网格入口，员工可处理现场桌台 |

### 低保真线框

```text
[员工工作台]
确认到店 / 开台 / 关台 / 标记未到

[待核实]
3
用户已提交到店，等待员工确认

[今日预约]
- 陈先生  B01 20:00-22:00  待核实
- 李女士  A01 22:30-23:30  待到店

[桌台网格入口]
查看40张桌台状态
```

## 6. 商家后台首页

路由：`pages/merchant-dashboard/index`

### 信息架构

| 层级 | 模块 | 内容 | 交互 |
|---|---|---|---|
| 1 | 后台标题 | 小程序内简化后台定位 | 无 |
| 2 | 今日经营概览 | 今日预约数、当前空桌数 | 点击可进入对应明细页，MVP 可先不展开 |
| 3 | 配置入口 | 门店、桌台、价格、助教、活动、客户、爽约限制 | 进入 `pages/merchant-config/index` 或 `pages/no-show-locks/index` |
| 4 | 风险提醒 | 爽约限制、满额活动、停用/维修桌台 | MVP 可作为入口文案，不做复杂报表 |

### 关键状态

| 状态 | 页面表现 | 操作规则 |
|---|---|---|
| 数据正常 | 显示今日预约数、空桌数、配置入口 | 配置入口为后台首页主行动 |
| 无预约 | 今日预约数为 0 | 不隐藏指标，避免商家误判缺模块 |
| 空桌不足 | 当前空桌数低 | 后续可提示查看桌台网格或运营调整 |
| 有爽约限制 | 风险提醒显示待处理数量 | 点击进入 `pages/no-show-locks/index` |
| 有配置缺失 | 配置入口提示门店、桌台、价格等待完善 | 点击进入 `pages/merchant-config/index` |
| 接口失败 | 显示重试，不展示错误数字 | 避免后台数据误导运营决策 |

### 低保真线框

```text
[商家后台]
小程序内简化后台，一期用于配置和查看数据

[今日预约 2] [当前空桌 37]

[配置入口]
门店 / 桌台 / 价格 / 助教 / 活动 / 客户 / 爽约限制

[风险提醒]
- 爽约限制待处理
- 满额活动需关注
- 维修/停用桌台需维护
```

## 7. 四屏状态联动

| 触发 | 状态变化 | 影响页面 |
|---|---|---|
| 用户创建预约 | 预约进入“待到店”，桌台进入“已预约” | 预约页、我的预约、员工工作台、商家后台 |
| 用户点击“我已到店” | 预约进入“待核实” | 员工工作台待核实数量增加 |
| 员工确认到店 | 预约进入“已到店” | 到店核实页可继续开台 |
| 员工开台 | 预约进入“进行中”，桌台进入“使用中” | 员工工作台、桌台网格、首页空桌数 |
| 员工关台 | 预约进入“已完成”，桌台进入“空闲/清洁中” | 首页空桌数、商家后台空桌数 |
| 员工标记未到 | 预约进入“未到店”，生成爽约限制 | 预约页阻止 3 天内再次预约，商家后台可处理 |
| 活动满额 | 活动报名拒绝或显示满额 | 用户首页近期活动、活动详情 |

## 8. 设计验收清单

- 用户首页能在首屏看见门店、空桌、空闲助教、立即预约、近期活动。
- 预约页能表达时间、桌台、助教、提交确认四步，不把不可用资源误呈现为可选。
- 员工工作台优先暴露待核实数量，并能进入到店核实处理链路。
- 商家后台首页以概览和配置入口为主，不做复杂报表。
- 四屏文案与状态名保持一致：待到店、待核实、已到店、进行中、已完成、未到店、已释放。
- 异常状态覆盖加载中、空状态、接口失败、冲突、爽约限制、重复提交。
