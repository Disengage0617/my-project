## 用户手动复测步骤

1. 在当前微信开发者工具中清缓存并重新编译。
2. 打开小程序首页，进入预约页。
3. 打开 DevTools 控制台和云函数调用相关日志面板。
4. 在预约页选择桌型“独牙”。
5. 观察页面是否还出现 `Cannot find module './src/handlers'` 或 `errCode: -1` 之类云函数启动错误。
6. 若模块错误消失，继续观察桌台列表：
   - 预期至少不再出现 `Cannot find module './src/handlers'`。
   - 若仍显示独牙 0 张，则下一步不再归因于 `src/handlers` 模块缺失，需检查真实云数据库 `billiard_table` 是否有 C01-C08、`table_type=duya`、`enabled=true`、可用状态。
7. 尝试切换“普台/银腿/独牙”各一次，确认是否只有独牙异常，还是所有桌型都报云函数错误。
