# 前端路由与信息架构

## 1. 范围

本目录面向小程序前端首轮骨架设计，只覆盖页面路由、信息架构、低保真页面结构、首批字段和交互状态。依据：

- `docs/业务规则确认表-台球厅私域运营小程序.md`
- `docs/下一轮开发任务包-台球厅私域运营小程序.md`
- `docs/MVP执行拆解-台球厅私域运营小程序.md`
- `docs/台球厅私域运营小程序第一轮方案.md`

一期边界：

- 不做支付、定金、退款。
- 不做桌台二维码和硬件接入。
- 商家端为小程序内简化后台。
- 用户提交“我已到店”，员工核实后确认到店并开台。
- 支持桌台预约、助教单独预约、活动展示与报名。

## 4. 用户端信息架构

### 首页

- 门店状态：营业中、24 小时营业、地址、电话。
- 资源概览：当前空桌数、空闲助教数。
- 快捷操作：立即预约、预约助教、查看价格。
- 今日价格：按当前时段显示各桌型价格。
- 活动入口：推荐活动卡片。
- 我的当前预约：有进行中或待到店预约时置顶提醒。

### 预约页

预约流程控制在 5 步内：

1. 选择日期和开始时间。
2. 选择时长。
3. 选择桌型或具体桌台。
4. 填写人数、助教需求、备注。
5. 确认价格、规则并提交。

关键规则：

- `start_time >= now + 30分钟`。
- 同桌台同时间段不可重复预约。
- 未到店限制期内不可预约。
- 提交前展示预计价格、保留规则、取消规则。

### 我的预约

- 状态分组：待到店、待核实、已到店、进行中、已完成、已取消、未到店。
- 卡片展示：预约时间、桌台、桌型、助教、状态、操作按钮。
- 用户操作：查看详情、我已到店。

## 5. 员工端信息架构

### 工作台

- 今日核心数：今日预约、待核实、使用中桌台、超时未到。
- 待处理列表：待核实、待开台、待关台、超时未到。
- 快捷入口：今日预约、桌台网格、助教状态。

### 到店核实页

- 用户信息：昵称、手机号授权状态、预约次数、爽约记录提示。
- 预约信息：时间、桌台、桌型、人数、助教、备注。
- 操作：确认到店、驳回到店、标记未到。
- 二次确认：标记未到会触发 3 天预约限制。

## 6. 商家后台信息架构

### 后台首页

- 经营概览：今日预约、当前空桌、使用中桌台、新增客户、活动报名。
- 配置完整度：门店、桌台、价格、助教、活动。
- 待处理：待核实预约、超时未到、待审核活动报名、爽约限制解除申请。
- 快捷配置：门店、桌台、价格、活动、助教。

## 7. 权限与可见性

| 能力 | 用户 | 员工 | 店长/商家 |
|---|---:|---:|---:|
| 创建预约 | 是 | 可代操作，待确认 | 是 |
| 提交到店 | 是 | 否 | 否 |
| 确认到店 | 否 | 是 | 是 |
| 开台/关台 | 否 | 是 | 是 |
| 标记未到 | 否 | 是 | 是 |
| 解除 3 天限制 | 否 | 否 | 是 |
| 配置门店/桌台/价格 | 否 | 否 | 是 |
| 查看客户手机号 | 本人 | 受限 | 是 |

## 8. 待确认依赖

- 桌台真实编号和现场区域命名。
- 每次预约最短/最长时长。
- 预约迟到多久释放桌台。
- 用户是否允许主动取消预约。
- 助教计费单位和服务时长。
- 活动报名默认是否需要审核。
- 未到店后是否允许申诉。
