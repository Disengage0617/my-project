## 3. Payload / 返回结构基线

- 统一入口：`cloudfunctions/api/index.js`。

## 5. 权限与状态机基线

- 用户个人读写：依赖 `wxContext.OPENID`，不信任前端传入 openid。

  - 商家配置、价格、助教/活动配置、页面配置、素材管理、爽约解除、完整手机号、配置写入。
- 跨门店保护：
  - `assertStaffPermission` 按 `store_id + openid + enabled` 校验。
  - 资源操作前校验资源归属。
