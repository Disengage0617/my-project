4. 菜单跳转覆盖到位

5. 只读列表页符合“不接支付”范围
   - `mine-feature/index.js` 支持 `orders/coupons/member/wallet/assistant/campaigns/support`。
   - 储值文案明确“当前版本仅展示后台配置余额，不接支付”。
   - 优惠券、会员权益文案说明由商家后台配置后展示。

   - `api.call("getMineCenter")` mock smoke 返回 profile、wallet、coupons、orders、reservations、assistantReservations、campaignRegistrations、noShowLocks。
