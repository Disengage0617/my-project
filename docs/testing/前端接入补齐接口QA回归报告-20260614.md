## 缺陷与风险

### P1 活动报名真实接口会因缺少手机号授权失败

- 位置：`miniprogram/pages/campaign-registration/index.js`
- 复现路径：进入活动报名页 -> 默认 `profile.phone` 为空 -> 点击提交报名 -> 调用 `createCampaignRegistration`
- 真实接口依据：`cloudfunctions/api/src/rules.js` 中 `assertAuthorizedProfile` 要求 nickname 和 phone；phone 为空会抛 `PHONE_REQUIRED`
- 当前表现：本地 mock 返回报名成功，真实云函数预计返回失败 toast
- 建议负责 agent：前端工程师 Agent
- 修复建议：补手机号授权入口或在提交前拦截并提示授权手机号；mock 也应模拟 `PHONE_REQUIRED`，避免本地误判成功

### P2 预约详情真实返回缺少桌台展示字段

- 位置：`miniprogram/pages/reservation-detail/index.js`
- 复现路径：从真实预约列表进入详情页 -> 调用 `getReservationDetail`
- 真实接口依据：`cloudfunctions/api/src/handlers.js` 当前直接返回 reservation 文档，没有 join 桌台；前端仅回退显示 `table_id`
- 当前表现：mock 下可显示 `A01/普台`；真实接口大概率显示桌台 ID，桌型为空
- 建议负责 agent：后端工程师 Agent 或前端工程师 Agent
- 修复建议：后端 `getReservationDetail` 返回 table 摘要，或前端按 `table_id` 二次获取桌台信息并归一化
- 后端修复状态：已修复。`getReservationDetail` 已返回 `table` 摘要，并补充 `tableCode/table_code/tableType/table_type_name` 顶层兼容字段；后端 `npm test` 21/21 通过。

### P2 WXML 双引号嵌套存在编译风险

- 位置：多处 WXML，例如 `miniprogram/pages/campaign-registration/index.wxml` 的 `{{profile.phone || "待授权"}}`
- 复现路径：微信开发者工具编译相关页面
- 当前表现：本地粗扫发现双引号嵌套；当前 shell 无法确认微信编译器实际结果
- 建议负责 agent：前端工程师 Agent
- 修复建议：将 WXML 表达式内字符串默认值改为单引号，或提前在 JS 中计算展示文本，减少模板表达式复杂度
