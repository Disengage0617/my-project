# 首页 Dark Neon 样式未生效 P0 修复报告

日期：2026-06-14

## 本轮执行 agent

- 前端工程师 Agent

## 根因判断

- 真实微信开发者工具截图中导航栏和 tabBar 为深色，但页面主体为白底裸文本，说明 `app.json` 生效，首页主体 WXSS 未正确命中。
- 修复前 `miniprogram/pages/home/index.wxss` 只有 `@import "../../app.wxss"` 和少量局部规则。
- 一旦微信开发者工具缓存、编译或 `@import` 链路失败，首页主体就没有 `.page`、`.hero`、`.panel`、`.button`、`.tag` 等样式，直接退回裸文本。
- 因此本轮将首页改为自包含 WXSS，不再依赖 `@import "../../app.wxss"` 才能呈现主体视觉。

## 修复文件

- `miniprogram/pages/home/index.wxss`
- `miniprogram/app.wxss`
- `docs/testing/首页DarkNeon样式未生效P0修复报告-20260614.md`
- `docs/worklog.md`

## 修复内容

- 首页 `index.wxss` 移除 `@import "../../app.wxss"`。
- 首页 `index.wxss` 内置完整 Dark Neon Club 主体样式：
  - `page`
  - `.page`
  - `.hero`
  - `.hero-metrics`
  - `.metric-tile`
  - `.button`
  - `.grid`
  - `.panel`
  - `.card`
  - `.tag`
  - `.list-item-title`
- `app.wxss` 中非标准 `font-weight: 850` 改为 `800`，降低微信 WXSS 编译兼容风险。
