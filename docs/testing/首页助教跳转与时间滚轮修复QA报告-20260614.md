## 通过项

1. 首页助教卡跳转修复已落地
   - `miniprogram/pages/home/index.wxml` 中助教卡仍绑定 `bindtap="goAssistants"`。
   - `miniprogram/pages/home/index.js` 中 `goAssistants()` 已改为 `wx.switchTab({ url: "/pages/assistant-list/index" })`。
   - `pages/assistant-list/index` 是底部 Tab 页面，使用 `switchTab` 符合小程序跳转规则。

2. 预约页时间滚轮防回弹机制已落地
   - `miniprogram/pages/reservation/index.wxml` 的 `picker-view` 已增加：
     - `bindpickstart="startTimePicking"`
     - `bindchange="changeTimePicker"`
     - `bindpickend="endTimePicking"`
   - `miniprogram/pages/reservation/index.js` 已增加：
     - `pendingTimePickerValue`
     - `isPickingTime`
     - `startTimePicking`
     - `endTimePicking`
     - `commitTimePickerValue`
     - `normalizePickerValue`
   - 滚动中仅写 `pendingTimePickerValue`，滚动结束后统一提交到 `timePickerValue` 与 `startTime`，可降低受控 value 反向回弹风险。

3. 5 分钟粒度仍保留
   - `buildTimePickerData()` 中分钟列仍为 `Array.from({ length: 12 }, (_, index) => pad(index * 5))`。
   - 可选分钟为 `00/05/10/.../55`。

4. 顶部展示值与提交值来源一致
   - 顶部展示使用 `{{startTime}}`。
   - `commitTimePickerValue()` 同步更新 `startTime`。
   - `submitReservation()` 使用 `buildStartAt(this.data.startTime)` 生成 payload `startTime`。

5. 提交成功跳转修复已落地
   - `submitReservation()` 成功后已改为 `wx.navigateTo({ url: "/pages/my-reservations/index" })`。
   - `pages/my-reservations/index` 当前不是底部 Tab 页面，使用 `navigateTo` 符合路由类型。
