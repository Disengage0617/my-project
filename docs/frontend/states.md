# 页面状态与交互状态

## 1. 预约状态机

| 状态 | 面向用户文案 | 员工/商家含义 | 用户可见操作 | 员工可见操作 |
|---|---|---|---|---|
| 待确认 | 等待确认 | 预约已提交，等待系统或员工确认 | 查看详情 | 确认、取消 |
| 待到店 | 待到店 | 已预约，等待用户到店 | 我已到店、查看详情 | 标记未到、取消 |
| 待核实 | 等待员工核实 | 用户已提交到店，员工需核实 | 查看详情 | 确认到店、驳回、标记未到 |
| 已到店 | 已到店 | 员工已核实，可开台 | 查看详情 | 开台 |
| 进行中 | 使用中 | 已开台 | 查看详情 | 关台 |
| 已完成 | 已完成 | 已关台 | 查看详情 | 查看记录 |
| 已取消 | 已取消 | 预约取消 | 查看详情 | 查看记录 |
| 未到店 | 未到店 | 员工标记未到，触发 3 天限制 | 查看限制说明 | 查看记录 |
| 已释放 | 已释放 | 超时或异常释放资源 | 查看详情 | 查看记录 |

状态流转：

```text
待确认 -> 待到店
待到店 -> 待核实        用户点击“我已到店”
待核实 -> 已到店        员工确认到店
待核实 -> 待到店        员工驳回误点
已到店 -> 进行中        员工开台
进行中 -> 已完成        员工关台
待到店/待核实 -> 未到店 员工标记未到
待到店 -> 已释放        超时释放，具体时间待确认
任意未履约状态 -> 已取消 取消规则待确认
```

## 5. 首批页面通用状态

### 加载中

- 首页：显示门店、资源、价格、活动骨架屏。
- 预约页：桌台列表加载时保留已选日期和时间。
- 员工工作台：统计卡片和待处理列表分别加载。
- 后台首页：配置完整度和待处理列表分别加载。

### 空状态

| 场景 | 文案方向 | 下一步 |
|---|---|---|
| 无空桌 | 当前时段暂无空桌 | 推荐最近可预约时间或同类型桌台 |
| 无活动 | 暂无活动 | 引导立即预约 |
| 无助教可约 | 当前无空闲助教 | 支持只预约桌台或换时间 |
| 无我的预约 | 还没有预约 | 立即预约 |
| 员工无待处理 | 暂无待处理事项 | 查看今日预约或桌台网格 |
| 后台未配置 | 还未完成基础配置 | 进入对应配置页 |

### 错误状态

| 错误 | 触发 | 前端处理 |
|---|---|---|
| 预约时间过近 | `start_time < now + 30分钟` | 禁用提交，提示最早可预约时间 |
| 桌台冲突 | 同桌台时间重叠 | 展示冲突提示和替代时段 |
| 未到店限制中 | `no_show_record` 未过期 | 阻止预约，展示限制结束时间 |
| 活动未授权 | 未授权昵称或手机号 | 拉起授权后再提交 |
| 活动满额 | 名额已满 | 禁用报名 |
| 权限不足 | 普通员工访问商家能力 | 提示无权限并返回工作台 |
| 配置缺失 | 门店/价格/桌台未配置 | 商家端提示补配置，用户端展示维护中 |

## 6. 首批按钮状态

| 按钮 | 可用条件 | 禁用/确认 |
|---|---|---|
| 立即预约 | 门店已配置且有可约资源 | 无空桌时跳转预约页并推荐时间 |
| 提交预约 | 时间合法、桌台可约、规则已确认 | 冲突或未到限制时禁用 |
| 我已到店 | 预约状态为待到店 | 二次确认可选，防误点 |
| 确认到店并开台 | 预约状态为待核实，员工有权限 | 成功后状态进入进行中 |
| 驳回到店 | 预约状态为待核实 | 状态回到待到店 |
| 标记未到 | 状态为待到店或待核实 | 必须二次确认，会限制 3 天 |
| 关台 | 预约状态为进行中 | 关台后选择空闲或清洁中 |
| 解除限制 | 店长/商家权限 | 必填解除原因 |

## 7. 关键弹窗

### 预约提交确认

字段：

- 预约时间
- 桌台/桌型
- 人数
- 助教需求
- 预计价格
- 不收定金提示
- 到店核实规则

操作：

- 确认提交
- 返回修改

### 标记未到确认

字段：

- 用户昵称
- 预约时间
- 桌台
- 限制规则：标记后 3 天内不可预约

操作：

- 确认标记未到
- 取消

### 解除未到限制

字段：

- 用户昵称
- 限制开始时间
- 限制结束时间
- 解除原因

操作：

- 确认解除
- 取消

## 8. 待确认项对前端影响

| 待确认项 | 影响页面 |
