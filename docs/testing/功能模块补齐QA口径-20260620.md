## 2. 测试分层

| 分层 | 后续测试目标 | 当前口径 |
|---|---|---|
| 本地 mock | 验证小程序和 Web 后台在 mock 数据下的页面链路、字段展示、空态、错误态、防重复提交 | 只证明前端/后台 mock 链路可用，不代表真实云端通过 |
| 云函数本地测试 | 验证 action、payload、返回结构、权限、参数校验、状态机、幂等和错误码 | 以后端补齐后的 `cloudfunctions/api npm test` 为准 |
| Web 后台 Playwright | 验证后台本地页面可读、核心按钮可点、保存/发布链路可观察、控制台无业务 JS 错误 | 继续区分 mock 后台和真实云函数接入 |
| 微信开发者工具 GUI/真机 | 验证小程序真实组件、跳转、授权、滚动、弹窗、移动端体验和多角色操作 | 需要微信开发者工具或真机条件，不由静态检查替代 |
| 真实云端 smoke | 验证部署后云函数、真实数据库、真实账号角色、最小业务闭环 | 需要用户授权云端写入和测试账号条件 |

## 3. P0 覆盖清单

| 模块 | 必测点 |
|---|---|
| 预约与我的预约 | 日期/时段/时长、按时段查可用桌台、预计价格、提交防重复、成功跳转、状态筛选、详情入口、状态文案一致 |
| 预约履约闭环 | 创建预约、提交到店、员工核实、开台、关台、释放、标记爽约、解除限制 |
| 权限与越权 | 普通用户、员工、店长/owner、禁用员工、跨门店访问；写操作必须校验身份、权限和资源归属 |
| 商家配置 | 门店、40 桌、价格、助教、活动配置读取/保存；字段非法、金额非法、停用有预约桌台、审计日志 |
| 活动报名 | 列表/详情、手机号授权或填写、报名、名单、审核/拒绝、重复报名、名额已满、手机号脱敏 |
| 助教预约 | 助教列表/详情、时段选择、预约提交、员工确认、时段冲突、停用助教、非法状态流转 |
| 桌台状态与爽约限制 | 空闲/使用中/清洁/维修/停用切换、解除原因、权限提示、审计日志、3 天限制 |
