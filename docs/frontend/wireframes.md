# 低保真页面结构

## 1. 设计原则

- 首屏优先展示“当前可用资源”和“下一步动作”。
- 用户预约流程不超过 5 步。
- 员工履约操作尽量 2 步内完成。
- 状态颜色保持一致：空闲、已预约、使用中、清洁中、维修中、停用、异常。
- 空状态必须给下一步，不只展示空文案。

```text
├──────────────────────────────┤
│ 我的当前预约                  │
│ 19:30 普台 A03 · 待到店        │
│ [查看详情] [我已到店]          │
├──────────────────────────────┤
│ 今日价格                      │
│ 普台 58/小时  银腿 68/小时     │
│ 独牙 88/小时  金腿 108/小时    │
│ [查看全部价格]                 │
├──────────────────────────────┤
│ 推荐活动                      │
│ 活动封面 / 标题 / 时间 / 名额  │
│ [查看活动]                     │
├──────────────────────────────┤
│ 门店信息                      │
│ 地址 电话 预约规则             │
└──────────────────────────────┘
```

首批字段：

| 区块 | 字段 |
|---|---|
| 门店 | `store_name`、`business_status`、`business_hours`、`address`、`phone` |
| 资源 | `available_table_count`、`available_assistant_count` |
| 当前预约 | `reservation_id`、`start_time`、`table_name`、`table_type`、`status` |
| 价格 | `current_period`、`table_type`、`price_per_hour`、`member_discount` |
| 活动 | `campaign_id`、`cover_url`、`title`、`start_time`、`quota_status` |

关键交互：

- 点击“立即预约”进入预约页。
- 有待到店预约时展示“我已到店”。
- 点击“我已到店”调用提交到店，成功后状态变为待核实。
- 无当前预约时隐藏当前预约区块。

## 3. 用户预约页 `/pages/user/reserve/index`

```text
┌──────────────────────────────┐
│ 预约桌台                      │
├──────────────────────────────┤
│ 日期                           │
│ 今天 明天 周一 周二 ...         │
├──────────────────────────────┤
│ 开始时间                       │
│ 18:00 18:30 19:00 19:30 ...    │
│ 提示：最早可预约30分钟后         │
├──────────────────────────────┤
│ 时长                           │
│ [-] 2小时 [+]                  │
├──────────────────────────────┤
│ 桌型/桌台                       │
│ 筛选：全部 普台 银腿 独牙 金腿   │
│ A01 空闲 58/时                  │
│ A02 已预约 20:30后可约           │
│ A03 使用中                      │
├──────────────────────────────┤
│ 附加信息                       │
│ 人数  助教需求  备注             │
├──────────────────────────────┤
│ 预计价格：116 元                │
│ 规则：不收定金，到店后员工核实    │
│ [提交预约]                      │
└──────────────────────────────┘
```

首批字段：

| 类型 | 字段 |
|---|---|
| 时间 | `date`、`start_time`、`duration_minutes`、`end_time` |
| 桌台 | `table_id`、`table_no`、`table_type`、`area_name`、`table_status`、`next_available_time` |
| 预约 | `people_count`、`assistant_required`、`assistant_id`、`remark` |
| 价格 | `price_rule_id`、`estimated_amount`、`member_discount` |
| 规则 | `min_advance_minutes=30`、`no_deposit=true`、`rule_confirmed` |

关键交互：

- 时间不满足提前 30 分钟时禁用提交，并提示最近可预约时间。
- 选择已预约或使用中桌台时不可提交，显示可替代时段或同类型空桌。
- 勾选助教需求后展示助教选择入口。
- 提交前必须确认规则。
- 创建成功后跳转预约详情或我的预约。

```text
│ 今日预约 32  待核实 4          │

│ 待处理                        │

├──────────────────────────────┤
```

首批字段：

| 区块 | 字段 |
|---|---|
| 统计 | `today_reservation_count`、`pending_arrival_count`、`using_table_count`、`timeout_count` |

关键交互：

- 点击待核实进入到店核实页。
- 超时未到可进入标记未到二次确认。
- 今日预约和桌台网格作为常用入口。

## 6. 到店核实页 `/pages/staff/arrival/detail`

```text
┌──────────────────────────────┐
│ 到店核实                      │
├──────────────────────────────┤
│ 用户信息                      │
│ 昵称 张三  手机 138****1234     │
│ 预约次数 5  爽约 0              │
├──────────────────────────────┤
│ 预约信息                      │
│ 19:30-21:30 普台 A03            │
│ 人数 2  助教 无  备注 ...       │
├──────────────────────────────┤
│ 状态流转                      │
│ 待到店 -> 待核实 -> 已到店       │
├──────────────────────────────┤
│ [确认到店并开台]               │
│ [驳回到店] [标记未到]           │
└──────────────────────────────┘
```

首批字段：

| 类型 | 字段 |
|---|---|
| 用户 | `user_id`、`nickname`、`phone_masked`、`reservation_count`、`no_show_count` |
| 预约 | `reservation_id`、`start_time`、`end_time`、`table_no`、`table_type`、`people_count`、`assistant_name`、`remark`、`status` |
| 操作 | `can_confirm_arrival`、`can_reject_arrival`、`can_mark_no_show` |

关键交互：

- 确认到店后可直接开台，预约状态进入进行中，桌台状态进入使用中。
- 驳回到店后状态回到待到店。
- 标记未到需二次确认，成功后释放桌台并写入 3 天限制。

- 配置未完成项给出直接入口。

- 首页不承载复杂报表，P0 只做运营概览和配置引导。
