## 修复点

- custom tabBar 增加 `attached` 与 `pageLifetimes.show` 路由同步兜底，根据当前页面 route 自动更新 selected。
- custom tabBar 点击时先更新 selected，`switchTab` 失败时回滚到当前 route 对应 selected。
- 助教列表页 `onShow` 同步 custom tabBar selected 为助教 tab。
- 我的页 `onShow` 同步 custom tabBar selected 为我的 tab，补齐五个 tab 页 selected 同步链路。
- 助教卡片点击增加 id 校验、`encodeURIComponent` 和 `navigateTo.fail` 提示。
- 助教预约页读取 query id 时增加安全解码。
- 清理上一轮不再使用的页面本地中转模块，避免 DevTools/包缓存继续出现 `pages/home/services/api.js` 这类混淆路径。

## 助教顶部标签不可交互处理方式

判断为筛选 tab，而不是静态卖点标签。已补齐：

- `人气推荐`：按预约次数降序展示。
- `职业认证`：展示有等级/认证信息的助教。
- `擅长打法`：展示有标签或简介的助教。
- `可约时间`：展示状态为空闲/available/free 的助教。
- 切换时更新选中态和列表；筛选为空时展示空态，不影响卡片预约跳转。
