# 台球馆商家管理后台

React + Vite Web 管理端原型，用于演示「经营后台 + 小程序首页装修器」能力。当前版本使用 `src/api.js` mock action 层，action 名称与后续云函数接入保持对齐。

## 本地运行

```bash
npm install
npm run dev
```

当前 dev server 已验证可在本机访问：

```text
http://127.0.0.1:5173/
```

## 本地构建

```bash
npm run build
```

## 已覆盖模块

- 经营看板：今日预约、桌台状态、营收、待处理事项。
- 预约看板：预约列表、状态、桌台、助教和到店信息。
- 客户信息：客户标签、消费、预约次数、风险状态。
- 门店配置：门店基础信息、营业时间、联系电话、地址、公告。
- 桌台配置：桌台类型、价格、状态和维护信息。
- 助教配置：助教资料、擅长方向、价格、上架状态。
- 活动配置：活动报名、人数、价格、上下架和时间信息。
- 报名管理：活动报名记录、手机号、状态和备注。
- 爽约限制：限制记录、解除状态和备注。
- 操作记录：后台操作审计日志。
- 素材库：小程序装修素材管理。
- 小程序装修器：首页模块配置、主题色、按钮文案、预览。

## 后续接真实云函数

后续接入真实云函数时，优先替换 `src/api.js` 内部实现，保持页面层继续通过 `call(action, payload)` 调用，避免大范围改动页面状态逻辑。
