## 测试用例清单

### 1. 经营后台看板

- TC-ADMIN-001：打开 Web 后台首页，验证门店名称、云环境、storeId、mock/cloud 模式提示准确。
- TC-ADMIN-002：验证今日预约、活动报名、爽约、客户数、营收/桌台利用率等核心指标展示，不出现 NaN、undefined、空白卡。
- TC-ADMIN-003：验证最近预约列表展示桌台、用户、时间、状态、手机号脱敏规则。
- TC-ADMIN-004：验证最近操作记录展示操作人、角色、动作、对象、时间。
- TC-ADMIN-005：mock 数据为空时，看板显示空态，不崩溃。
- TC-ADMIN-006：接口失败时显示可识别错误态，并可重试。

### 2. 门店、桌台、价格配置

- TC-CONFIG-001：编辑门店名称、地址、电话、营业时间、规则文案后保存，刷新后数据保持一致。
- TC-CONFIG-002：新增/编辑/停用桌台，验证桌型 + 编号展示，状态与价格绑定不丢失。
- TC-CONFIG-003：40 桌规模数据下，桌台列表筛选、滚动、保存性能可接受。
- TC-CONFIG-004：新增/编辑/停用价格规则，验证桌型、时段、价格、会员价、特殊日期校验。
- TC-CONFIG-005：非法价格、空桌台编号、重复编号、结束时间早于开始时间时阻止保存并提示。
- TC-CONFIG-006：保存门店、桌台、价格后，审计日志新增对应记录。

### 3. 助教、活动、客户运营

- TC-OPS-001：助教列表展示姓名、等级、价格、标签、状态、头像，至少覆盖初级/中级/高级/网红级。
- TC-OPS-002：新增/编辑/停用助教后，用户端助教列表和预约链路可读取最新配置。
- TC-OPS-003：活动列表展示名称、状态、报名人数、容量、时间、封面。
- TC-OPS-004：新增/编辑/发布/下线活动后，小程序首页活动模块和活动报名页联动正确。
- TC-OPS-005：活动容量为 0、已满、下线、过期时，用户端报名按钮和提示符合规则。
- TC-OPS-006：客户列表支持查看预约、报名、爽约记录，手机号等敏感信息按角色脱敏。

### 4. 装修器与素材库

- TC-DESIGN-001：素材库展示图片名称、类型、用途、预览图、上传/替换/删除状态。
- TC-DESIGN-002：上传或选择 Hero、店内活动、本店赛事、助教图片后，页面装修预览更新。
- TC-DESIGN-003：首页装修模块支持 Hero、桌型分类、实时桌台、活动、赛事、助教等模块开关和排序。
- TC-DESIGN-004：保存草稿不影响小程序线上展示，发布后才更新小程序读取配置。
- TC-DESIGN-005：发布页面配置后，`getPageConfig` 返回模块顺序、图片地址、文案和状态一致。
- TC-DESIGN-006：图片缺失、路径无效、模块配置为空时，小程序端降级到默认图和默认文案。

### 5. 小程序联动回归

- TC-LINK-001：后台更新门店营业时间后，小程序首页/预约页展示同步。
- TC-LINK-002：后台更新桌台和价格后，预约页桌台卡和价格摘要同步。
- TC-LINK-003：后台发布活动后，小程序首页活动入口、活动详情、报名页同步。
- TC-LINK-004：后台更新助教后，用户端 tab “助教”、助教列表、助教预约页同步。
- TC-LINK-005：后台装修发布后，小程序首页 Hero、活动、赛事、助教图片区分且命中最新配置。
- TC-LINK-006：mock 模式和 cloud 模式切换时，页面有明确环境提示，避免误测线上数据。

### 6. 权限与安全

- TC-AUTH-001：未登录或无效登录态访问后台时被拦截。
- TC-AUTH-002：店长/管理员可编辑门店、桌台、价格、助教、活动、装修器。
- TC-AUTH-003：普通员工只能查看或处理授权范围内数据，不能保存配置。
- TC-AUTH-004：跨 storeId 请求被拒绝，不能读取或修改其他门店数据。
- TC-AUTH-005：客户手机号、openid、备注等敏感字段按角色脱敏。
- TC-AUTH-006：直接调用管理 API 缺少权限、缺少 storeId、非法 payload 时返回明确错误码。

### 7. 审计日志

- TC-AUDIT-001：每次配置写操作产生审计日志，包含 action、operatorOpenid、operatorRole、targetType、targetId、before、after、reason、createdAt。
- TC-AUDIT-002：删除/停用类操作保留 before/after，不允许只有动作名没有数据快照。
- TC-AUDIT-003：审计日志支持按动作、对象、时间筛选。
- TC-AUDIT-004：看板最近操作与审计日志列表数据一致。
- TC-AUDIT-005：审计日志普通员工不可篡改，不提供删除入口。

### 8. 商业化演示路径

- TC-DEMO-001：全新演示环境从 mock 数据启动，后台首页可直接展示完整经营状态。

- TC-DEMO-003：演示过程中不要求真实部署、不写真实数据库，除非用户明确授权。
- TC-DEMO-004：演示数据可一键恢复或重新 seed，避免销售演示被上一次操作污染。
- TC-DEMO-005：商业化话术需要的“模板 + 代部署”能力在 README 或页面中能被验证，不出现未实现按钮。
