# 后端能力补齐说明 - 2026-06-14

## 新增/补强 action

- 商家配置：`manageStore`、`manageTables`、`managePriceRules`、`manageAssistants`、`manageCampaigns`。
- 桌台状态：`updateTableStatus`，支持 `idle`、`cleaning`、`repairing`、`disabled`，写入 `table_status_log`。
- 活动：`createCampaignRegistration`、`getCampaignRegistrations`，校验昵称/手机号、限额、防重复、审核状态、名单手机号脱敏。
- 助教：`createAssistantReservation`、`confirmAssistantReservation`、`updateAssistantStatus`、`getAssistantDetail`。
- 客户沉淀：`getCustomers`、`getCustomerProfile`，返回预约/到店/爽约/活动统计，普通员工手机号脱敏。
- 爽约限制：`getNoShowRecords`、`liftNoShowBan`，解除限制写 `audit_log`。

## 关键规则

- 所有写接口按 `store_id` 做门店隔离。
- `manager` 及以上可修改商家配置、解除爽约限制、查看完整手机号。
- `staff` 可操作桌台状态、预约状态、查看脱敏手机号。
- 桌台存在有效预约时，不允许直接切到 `disabled`。
- 活动报名必须有微信昵称和手机号；限额使用 `quota_used + participant_count <= quota_total`。
- 助教预约确认前会再次做时间冲突校验。
- 测试入口 action 仅保留为显式测试/初始化能力，不作为正式业务能力暴露。
